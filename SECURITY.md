# Política de seguridad

No publique vulnerabilidades, credenciales, cadenas de conexión, tokens, datos personales o medidas de salud en issues, commits o capturas.

Reporte el problema de forma privada al propietario del repositorio con:

- componente y versión;
- pasos mínimos de reproducción, sin datos reales;
- impacto esperado;
- mitigación temporal si existe.

El equipo debe contener el riesgo, preservar evidencia, rotar secretos afectados, corregir en una rama privada, probar en Staging y documentar el incidente. Production no se modifica fuera del proceso de aprobación y rollback.

Este proyecto es educativo y no ofrece un programa público de recompensas. Para tratamiento institucional de datos, use el canal formal que la entidad defina antes de Production.
